# ☁️ Cloud Journey

**Building cloud engineering skills, one hands-on project at a time.**
AWS-first, with principles that carry over to Azure and GCP.

> Frontend engineer moving into cloud and DevOps. This repo is my public, 
> working record of what I build and what I learn along the way.

## How I work
- **Build first, theory second.** Every phase ends with a project in this repo.
- **Infrastructure as code.** Anything I create in the cloud should be reproducible from code.
- **Security and cost by default.** Least-privilege IAM, no secrets in Git, billing alerts, and free-tier-only resources.
- **Documented as I go.** Each project has its own README covering the goal, architecture, how to run it, and what broke.
